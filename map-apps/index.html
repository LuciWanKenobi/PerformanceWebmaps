Mapping apps

Four plain JavaScript starters with weather overlays and no basemap.

  • MapLibre GL JS
  • Mapbox GL JS Public access token required
  • OpenLayers
  • Leaflet

Each app supports panning, zooming, weather overlays, benchmarking, and resetting the view.

Use the performance panel to compare point and layer workloads, repeat a fixed camera path, and export timing results.
